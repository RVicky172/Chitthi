Credit line for a photo, read from its name: "Photo by *Name* on *Pexels*" (linked) for Pexels photos, "AI picture · Provider model" for AI pictures, nothing for the user's own photos. Prop: `name` (the photo's name).

```jsx
const { PhotoCredit } = window.Chitthi;
<PhotoCredit name="Diya lamps (Pexels / Asha Rao #123456)" />
```
