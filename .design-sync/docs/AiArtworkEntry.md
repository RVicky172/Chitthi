"Create a picture with AI" button that opens the AI picture panel: a description (pre-filled from the occasion / month), a style, then candidates in the shape of the selected photo slot; the chosen picture is saved to the library, credited as AI, and put on the card. `wide` shows the panel open, laid out for the full-screen library. Uses the user's own picture service from Settings → AI.

```jsx
const { AiArtworkEntry } = window.Chitthi;
<AiArtworkEntry />
```
