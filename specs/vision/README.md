# Vision

Multi-release initiatives for Chitthi: what we intend to build and why, and the original work-item breakdown. These
are input to the spec-driven workflow ([workflow.md](../workflow.md)): each work item becomes a numbered feature in
[roadmap.md](../roadmap.md) (P2.1 → `201`) with its own spec when it starts, and the roadmap holds its status from
then on. Product docs about how the app works today are in [docs/](../../docs); when a plan ships, its outcome is
written up there and the plan here is marked done.
